# Bank Loan Analytics Dashboard | Power BI
## 📊 Project Overview
This project presents an interactive Bank Loan Analytics Dashboard
developed using Microsoft Power BI.
The objective of this project is to analyze loan applications,
funding, repayments, customer borrowing patterns, loan purposes,
loan terms, home ownership, and loan performance.
The dashboard converts loan data into meaningful KPIs and
business insights to support data-driven decision-making.
---
## 🎯 Project Objectives
- Analyze overall loan application performance
- Track total funded loan amount and repayments
- Monitor average interest rate and DTI ratio
- Compare Good Loans vs Bad Loans
- Analyze monthly loan application trends
- Identify popular loan purposes
- Analyze loan applications by loan term
- Understand loan applications by home ownership
- Analyze loan performance by loan status
- Provide an interactive business intelligence dashboard

## 📈 Dashboard Analysis
### 1. Loan Overview
The overview page provides a high-level view of the loan portfolio.
It includes:
- Total Loan Applications
- Total Loan Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio
- Monthly Loan Application Trend
- Geographical Distribution of Loan Applications
The monthly trend shows variation in loan application volume
throughout the year.
---
### 2. Loan Application Analysis
This page analyzes customer loan preferences.
Key analyses include:
- Loan Application by Term
- Loan Application by Purpose
- Loan Application by Home Ownership
The dashboard shows that 36-month loans account for 73.2%
of applications, while 60-month loans account for 26.8%.
Debt Consolidation is the largest loan purpose in the dataset.
---
### 3. Loan Performance Analysis
The performance page compares Good Loans and Bad Loans.
Key metrics include:
- Good Loan Applications
- Bad Loan Applications
- Funded Amount vs Repayment
- Loan Applications by Loan Status
- Average Interest Rate by Loan Status
- Average DTI Ratio by Loan Status
Good Loan Applications represent 86.18% of total applications,
while Bad Loan Applications represent 13.82%.
---
## 💡 Key Business Insights
- The majority of loan applications fall under Good Loan status.
- 36-month loan terms are significantly more common than
  60-month terms.
- Debt Consolidation is the dominant loan purpose.
- Rent and Mortgage customers represent the largest
  home-ownership segments.
- Fully Paid loans represent the largest loan-status category.
- Loan application volume varies across months.
- Interest rate and DTI ratio differ across loan statuses,
  providing useful indicators for portfolio analysis.
